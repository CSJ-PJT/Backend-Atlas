## 공개 기준

- `reviewStatus=reviewed`만 공개한다.
- 모든 DAY·실습·문항은 하나 이상의 검수 출처를 가진다.
- 현재 운영 버전과 최신 문서가 다를 수 있는 기술은 적용 전 버전 확인 메모를 둔다.
- 개인 연락처·사설 IP·인증정보·비공개 이력·답안 원문을 포함하지 않는다.
- 특정 조직이나 개인의 평가가 아니라 범용 Java, Spring, Database, Batch, Messaging, Distributed Systems, System Design 학습만 제공한다.

## 평가 기준

- 회상, 객관식, 시나리오, 단답, 구술, 코드, SQL, 디버깅, 시스템 설계를 지원한다.
- 객관식은 정답과 해설을 자동 평가한다.
- 서술형은 답을 먼저 입력해야 기준 답안을 볼 수 있다.
- 기준 답안은 정의뿐 아니라 메커니즘·증거·경계를 포함한다.
- 틀리거나 어렵다고 평가한 문항은 질문 ID와 약점 태그만 복습 큐에 남긴다.
