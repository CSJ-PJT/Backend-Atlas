# Candidate Fact and Claim Boundaries

Interview Lab은 답변을 더 그럴듯하게 만들기보다 사실 경계를 지키도록 설계한다.

- 티머니와 야놀자는 프로젝트 투입처와 실제 소속회사를 구분한다. 최종 증빙 전에는 고용관계를 단정하지 않는다.
- SAP ERP 자체 개발이 아니라 SAP ERP REST API 연동이다.
- Archive/Atlas는 회사 실무가 아닌 개인 프로젝트다.
- 개인 프로젝트는 합성·비식별 데이터 중심이며 대규모 상용 트래픽 실적으로 표현하지 않는다.
- AI 도구 활용과 본인의 요구사항, 경계, 계약, 검증 책임을 분리한다.
- 자체 LLM 학습·GPU 모델 서버 운영, 직접 DSP 실무, Staff 인사관리 경험을 만들지 않는다.
- 약 855배는 처리 건수와 실행 시간을 분당 처리량으로 정규화한 비교다. 동일 건수의 단순 실행시간 비교가 아니다.

비공개 원본은 Git에서 제외된 `private/interview-candidate-profile.json`에만 저장한다. 공개 앱은 `publicSafe` 사실과 금지 주장 ID만 사용한다.
